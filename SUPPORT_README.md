# Sapronem Support Bot

Отдельный бот поддержки для пользователей Sapronem.


## Запуск

```bash
python support_bot.py
```

## Как работает

Пользователь пишет `/start`, затем отправляет сообщение.
Сообщение копируется администраторам поддержки.
Администратор отвечает **reply на скопированное сообщение** — ответ отправляется пользователю.

Для основного Sapronem этот бот отдельный: ему нужен отдельный Telegram bot token и отдельный Railway service.
