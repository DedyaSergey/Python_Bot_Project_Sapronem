# Sapronem 1.5

## Railway Variables
- `TOKEN` — Telegram bot token
- `DB_PATH` — путь к постоянной SQLite базе (например `/data/bot.db`)
- `ADMIN_IDS` — Telegram ID владельца/админов, через запятую

## Админка
В личке боту: `/admin`

Доступ только для ID из `ADMIN_IDS`.

Возможности:
- статистика;
- поиск пользователя по Telegram ID;
- выдать/забрать сапы;
- выдать/снять VIP;
- история Stars-платежей;
- рассылка пользователям.

Токен и ID админа в код не записываются.
