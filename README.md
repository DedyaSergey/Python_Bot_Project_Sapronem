## Sapronem 1.7.0

## Админка


Доступ только для ID из `ADMIN_IDS`.

Возможности:
- статистика;
- поиск пользователя по Telegram ID;
- выдать/забрать сапы;
- выдать/снять VIP;
- история Stars-платежей;
- рассылка пользователям.
- фермерство
- коллекция валют/предметов( в будущем)

Токен и ID админа в код не записываются.
