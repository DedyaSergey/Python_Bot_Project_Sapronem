# Sapronem 1.7.5
Telegram-бот с профилями, экономикой, фермерством, сезонами, достижениями, наградами, титулами, VIP и модерацией.

## Railway

Start command:
```bash
python bot.py
```

Переменные:
- `TOKEN` — токен основного бота.
- `ADMIN_IDS` — Telegram ID владельца/глобальных администраторов через запятую.
- `DB_PATH` — путь к SQLite, рекомендуется Railway Volume.

## Глобальный сезон

Владелец открывает `/admin` в личных сообщениях боту и нажимает:
`🌐 Глобальный сезон: ВЫКЛ`.

После включения очки сезона, полученные в любых группах, складываются в единый рейтинг.
