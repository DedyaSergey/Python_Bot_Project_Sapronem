# Sapronem 1.13

Основной Telegram-бот Sapronem.

## Railway

Переменные:
- `TOKEN` — токен основного бота.
- `ADMIN_IDS` — ID пользователей, которым доступна глобальная служебная `/admin`.
- `DEV_IDS` — ID разработчиков для `/dev`.
- `DB_PATH` — путь к SQLite, например `/data/bot.db` на Railway Volume.

Запуск:
`python bot.py`

## Админка группы

В группе администратор может использовать `/admin`.
Доступ проверяется через Telegram, поэтому обычный участник не получит панель.

Обычные групповые возможности намеренно ограничены: статистика, журнал, настройки, выдача сапов с лимитом 300 💎/неделю и существующая система наград.

## Developer Panel

`/dev` доступна только `DEV_IDS` и содержит сильные функции проекта.
