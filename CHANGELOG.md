# Sapronem 1.7.7
 Глобальное обновление
## 🌐 Глобальный сезон
- Владелец может включить/выключить единый сезон для всех групп из `/admin`.
- При включении очки нового режима суммируются между всеми чатами.
- Общий топ и награды становятся едиными для всех групп.
- Локальные сезонные очки сохраняются и не теряются при отключении глобального режима.
- Глобальная награда за прошлый сезон может быть забрана только один раз, независимо от группы.

## 🏷️ Сезонные титулы
- Топ-50 прошлого сезона получают разные памятные сезонные титулы.
- Титулы сохраняются в коллекции пользователя и не заменяют текущий экипированный титул автоматически.
- Титул содержит номер сезона, например `👑 Император сезона #34`.

## 🛠️ Админка
- Добавлена кнопка `🌐 Глобальный сезон: ВКЛ/ВЫКЛ`.
- После переключения владелец сразу видит обновлённую панель.
